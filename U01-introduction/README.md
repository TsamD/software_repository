# U01 — Introduction à la sécurité logicielle

## Objectifs

À l'issue de cette unité, vous serez capable de :

- distinguer la sécurité logicielle de la fiabilité ;
- expliquer les propriétés CIAAA (confidentialité, intégrité, disponibilité, authenticité et auditabilité) ;
- reconnaître les notions d'actif, de menace, de vulnérabilité, de vecteur d'attaque, de risque et de surface d'attaque ;
- expliquer les principaux principes de conception sécurisée ;
- appliquer ces notions à l'analyse d'incidents et à un scénario de conception.

## Pour aller plus loin — laboratoire facultatif

Le laboratoire **Threat Modeling** propose d'identifier les actifs, les menaces et les surfaces d'attaque d'une application fictive, puis de justifier des mesures de protection.

Ce laboratoire n'est **pas obligatoire**. Les étudiants qui souhaitent obtenir des **points bonus** peuvent remettre leur travail selon les consignes et l'échéance communiquées en cours.

Les modalités exactes d'attribution des points bonus seront confirmées par l'équipe enseignante.

## Prérequis

Notions générales de programmation et de fonctionnement d'une application web. Aucun outil de laboratoire ni environnement Docker n'est nécessaire pour cette unité.
